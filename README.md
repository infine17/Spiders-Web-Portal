## 🚀 How to Deploy This Portal on GitHub

```bash
# 1. Initialize git and commit
cd "C:\Users\Admin2025\Desktop\Spiders-Web-Portal"
git init
git add .
git commit -m "feat: Initial commit for Spider's Web Master Operations Portal"

# 2. Add remote and push to your new GitHub repository
git branch -M main
git remote add origin https://github.com/infine17/Spiders-Web-Portal.git
git push -u origin main
```

To enable the live website:
1. Open the repository on GitHub (`infine17/Spiders-Web-Portal`).
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** -> `main` / `/(root)`.
4. Your master portal will be live at `https://infine17.github.io/Spiders-Web-Portal/`!
